YouTube의 어떤 영상이든, 한 줄도 놓치지 마세요.

Twinsub는 영상에 자막 두 줄을 동시에 띄웁니다. 위에는 원문, 바로 아래에는 같은 문장을 내 언어로. 진짜 목소리를 들으며 원문을 읽으니 놓치는 말이 없습니다.

무료, 무제한, 로그인 없이
계정도, API 키도 필요 없고, 15분 뒤에 '체험 종료' 화면이 뜨지도 않습니다. 설치하고 영상을 열면 끝입니다.

번역은 내 컴퓨터에서
Chrome에 내장된 번역 기능을 사용해 한 줄씩 내 컴퓨터에서 밀리초 만에 번역합니다. 서버를 기다릴 일이 없고, 자막은 내 컴퓨터 밖으로 나가지 않습니다.

외국어 공부에 딱
원문은 위, 번역은 아래. 순서도 바꿀 수 있습니다. 스페인어 브이로그, 일본 애니 클립, 프랑스 요리 영상, 영어 강의까지. 원래 좋아하던 영상으로 언어를 익히세요.

지금 있는 자막 그대로
직접 만든 자막도, YouTube 자동 생성 자막도 모두 지원합니다. Twinsub가 자막을 켜고, 자막 메뉴에서 고른 언어를 따라가며, 다음 영상으로 넘어가도 계속 작동합니다.

못 알아들었다면? 물어보세요.
일시정지하고 이해가 안 되는 부분을 표시한 뒤 '설명'을 누르세요. AI가 원문을 바탕으로 관용구, 속어, 고유명사, 문화적 배경, 농담까지 설명해 줍니다. 하루 5번 무료. 표시한 부분과 앞뒤 몇 줄만, '설명'을 누를 때만 전송됩니다.
• Twinsub Pro: 한 달 1,000번 설명, 월 $4.99
• Twinsub 평생 이용권: 한 번 $14.90. 내 API 키 사용(OpenAI, Claude, Gemini, DeepSeek 등 또는 호환 엔드포인트). 설명은 Chrome에서 내가 고른 제공업체로 바로 가며 저희 서버를 거치지 않습니다. 키는 암호화되어 내 컴퓨터에만 저장됩니다.

내 마음대로
• 한국어, 영어, 일본어, 중국어, 스페인어, 프랑스어, 독일어 등 39개 언어로 번역
• 원문을 위로, 또는 번역을 위로
• 글자 크기와 화면 높이
• 번역만, 또는 원문만 보기
• 플레이어 하단 버튼 하나로 켜고 끄기

사용 방법
1. Twinsub를 설치합니다.
2. 자막이 있는 YouTube 영상을 엽니다.
3. 어떤 언어 조합을 처음 쓸 때는 노란 안내를 한 번 클릭하세요. Chrome이 몇 초 만에 번역 팩을 받습니다.
4. 이제 보기만 하면 됩니다.

데스크톱용 Chrome 138 이상이 필요합니다(Windows, Mac, Linux, ChromeOS). Twinsub는 YouTube 및 Google과 제휴하거나 승인받지 않았습니다.
