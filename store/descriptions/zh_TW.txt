在 YouTube 上看任何影片，每一句都看得懂。

Twinsub 同時幫影片配上兩行字幕：上面是原文，下面緊跟著同一句的中文。聽著原音、看著原文，哪一句都不會錯過。

免費、不限次數、不用登入
不用註冊帳號，不用填 API 金鑰，也不會看了 15 分鐘就跳出「試用期已結束」。裝好、打開影片，就這麼簡單。

翻譯就在你的電腦上完成
Twinsub 用的是 Chrome 內建的翻譯，每一句都在你的電腦上翻譯，幾毫秒就好。不用等伺服器，字幕也不會離開你的電腦。

學外語的好幫手
原文在上、譯文在下，也可以對調。看西班牙文 Vlog、日本動畫片段、韓綜、法國美食、英文公開課，在本來就喜歡的影片裡學語言。

上傳者字幕、自動產生的字幕都能用
Twinsub 支援上傳者提供的字幕和 YouTube 自動產生的字幕，會幫你開啟字幕，跟隨你在 YouTube 字幕選單裡選的語言，換到下一部影片也照樣有效。

沒聽懂？問一下
暫停，選取看不懂的地方，按「解釋」。AI 會根據原文講清楚：慣用語、俚語、人名地名、文化背景、梗和雙關。每天免費 5 次。只傳送你選取的內容和前後幾句，而且只在你按「解釋」時傳送。
• Twinsub Pro：每月 1000 次解釋，每月 US$4.99
• Twinsub 買斷版：一次 US$14.90。使用你自己的 API 金鑰（OpenAI、Claude、Gemini、DeepSeek 等，或任何相容的端點）。解釋由 Chrome 直接傳給你選的服務供應商，完全不經過我們的伺服器。金鑰加密後只存在你的電腦上。

照你的習慣來
• 可以翻譯成 39 種語言：中文（繁體、簡體）、日文、韓文、英文、西班牙文、法文、德文、葡萄牙文、俄文、阿拉伯文、越南文等
• 原文在上或譯文在上
• 字體大小、離底部的距離都能調
• 可以只看譯文，或只看原文
• 播放器控制列一個按鈕，隨時開關

怎麼用
1. 安裝 Twinsub。
2. 打開任何有字幕的 YouTube 影片。
3. 第一次用某個語言組合時，按一下黃色提示，Chrome 幾秒鐘就會下載好翻譯套件。
4. 開始看。

需要電腦版 Chrome 138 以上版本（Windows、Mac、Linux、ChromeOS）。Twinsub 與 YouTube、Google 沒有關聯，也未獲得其背書。
